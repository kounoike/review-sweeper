# 4. PR準備とレビューセッションを分離する

Date: 2026-08-21

## Context

Review Sweeperは、可能な限りユーザーが開く前にPRを準備済みにする。準備にはメタデータ取得、差分のキャッシュ、worktree作成、セットアップ、AIによる事前レビューを含める。

これらは、コードを読み、指摘を確認し、コメントを下書きし、レビューを送信する実際のレビューセッションとは異なる活動である。

## Decision

PR準備をレビューセッションとは別にモデル化する。

準備状態ではリモートデータ、キャッシュ済み差分、worktree、環境セットアップ、チェック、AIレビュー結果を追跡する。レビューセッション状態では進捗、閲覧済みファイル、コメント下書き、選択中の差分モード、最終レビュー判断を追跡する。

## Consequences

- PRを受信箱を止めずにバックグラウンドで準備できる。
- より深いローカル準備中でも、GitHubから提供された差分でレビューを開始できる。
- 準備の失敗をレビューの進捗を壊さずに表示できる。
- 複数の準備プロファイルとリソース制限をサポートできる。
