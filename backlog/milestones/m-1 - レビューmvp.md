## Description

GitHub PRを取得し、ローカル状態を安全に扱いながら、レビューの準備と差分確認を行える最初の実用的な流れを構築するマイルストーン。

## 対象タスク

- TASK-13: Windowsネイティブ実行バックエンド基盤を実装する
- TASK-14: Review InboxとPR概要を構築する
- TASK-15: GitHub差分ビューアーを構築する
- TASK-16: フルソース閲覧と差分位置の相互移動を実装する
- TASK-17: レビュー下書きと明示的な送信を実装する
- TASK-18: レビュー進捗・再レビュー・Checks表示を実装する
- TASK-19: 共有リポジトリとPR worktreeのライフサイクルを実装する
- TASK-20: ローカルworkspace状態を観測しPR差分から分離する
- TASK-21: PR Preparation状態とパイプラインを実装する
- TASK-22: 信頼ベースのworkspace setupを実装する
- TASK-23: Preparation schedulerと手動操作を実装する
- TASK-24: Windows向け外部エディター連携を実装する
- TASK-25: 読み取り専用AIレビューとFinding表示を実装する

## 完了条件

- レビュー対象のPRを取得し、受信箱で確認できる。
- GitHubの差分を統合・分割表示で確認できる。
- PRのリモート状態とローカルworktreeの変更を混同しない。
- 信頼されていないリポジトリのセットアップコマンドを自動実行しない。
- AI指摘は読み取り専用で、コメント投稿やレビュー送信はユーザー操作に限定される。
- 外部エディターやシェルでworkspaceを開ける。

## 次のマイルストーンへの条件

ユーザーが実際に1件のPRを取得し、準備し、差分をレビューして、必要なら外部ツールへ移れること。
