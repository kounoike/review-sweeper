## Description

GitHub PRを取得し、ローカル状態を安全に扱いながら、レビューの準備と差分確認を行える最初の実用的な流れを構築するマイルストーン。

## 対象タスク

- TASK-12: worktreeとローカルレビュー状態を管理する
- TASK-13: レビュー受信箱と差分MVPを構築する
- TASK-14: PR workspaceを安全に準備する
- TASK-15: 読み取り専用AIレビューを追加する
- TASK-16: 外部開発ツールを連携する
- TASK-17: MVP後にタスクを再整理する

## 完了条件

- レビュー対象のPRを取得し、受信箱で確認できる。
- GitHubの差分を統合・分割表示で確認できる。
- PRのリモート状態とローカルworktreeの変更を混同しない。
- 信頼されていないリポジトリのセットアップコマンドを自動実行しない。
- AI指摘は読み取り専用で、コメント投稿やレビュー送信はユーザー操作に限定される。
- 外部エディターやシェルでworkspaceを開ける。
- MVPの結果を踏まえて、ユーザーと次のマイルストーンを決め、Backlogに登録する。

## 次のマイルストーンへの条件

ユーザーが実際に1件のPRを取得し、準備し、差分をレビューして、必要なら外部ツールへ移れること。また、次のマイルストーンとその対象タスクが決まっていること。
