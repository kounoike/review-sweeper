## Description

Review Sweeperを実装・検討できる状態にし、MVPの前提となる設計判断を確定するマイルストーン。

## 対象タスク

- TASK-1: プロジェクトのセットアップ
- TASK-2: 提案中ADRを検討して確定する
- TASK-3: RustアプリケーションとUIフレームワークを技術調査する
- TASK-4: GitHub APIと認証・トークン保管を調査する
- TASK-5: UIデザインシステムと操作規約を決める
- TASK-6: 差分とGitHubレビューAPIを技術調査する
- TASK-7: ローカル状態・永続化・キャッシュ方式を調査する
- TASK-8: テスト戦略とfixtureを設計する
- TASK-9: アプリケーションのビルド方式を選定する
- TASK-10: GitHub ActionsのCI体制を構築する
- TASK-11: アプリケーションのリリース方法を選定する

## 完了条件

- Rustプロジェクトの構成、開発ツール、CI方針が決まっている。
- `mise`、Backlog.md、`adrs`を使った開発環境が再現できる。
- 提案中のADRについて、採用・修正・却下の判断が完了している。
- UIフレームワーク、GitHub連携、差分処理、永続化、テストの技術的な前提が整理されている。
- UIの共通デザインと操作規約が実装タスクから参照できる。
- アプリケーションのビルド、CI、リリースの方針と初回運用手順が決まっている。
- MVPの実装に必要な未解決の設計判断が洗い出されている。

## 次のマイルストーンへの条件

レビュー対象の状態、worktree、差分、PR準備の基本モデルを実装できる見通しが立っていること。
