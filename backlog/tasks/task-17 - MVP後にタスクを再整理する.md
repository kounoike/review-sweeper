## Description

MVPの実装とレビューを終えた時点で、ユーザーと次の開発方針を相談する。残っている要望、実装で得た知見、優先度、技術的な制約を確認し、次のマイルストーンの目的・対象・完了条件を決める。その結果に基づいてBacklogのタスクを分割・統合・削除・追加し、次の計画を作る。
